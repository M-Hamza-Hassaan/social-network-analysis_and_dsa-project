## ✨ Feature Overview

This upgraded app introduces a comprehensive suite of features to support social network analysis, interactive learning, and efficient data management.

### 1. Interactive Visualization with Plotly
- 🖱️ Hover tooltips showing all centrality scores and community info  
- 🔍 Clickable nodes with detailed information panels  
- 📏 Dynamic node sizing based on degree centrality  
- 🎨 Color coding by various centrality measures  
- 🔄 Zoom and pan capabilities  

### 2. Advanced Network Analysis
- ✅ PageRank centrality  
- ✅ Clustering coefficient  
- ✅ Network density metrics  
- ✅ Shortest path analysis with node selection  
- ✅ Connected components analysis  
- ✅ Community size distribution charts  
- ✅ Centrality correlation heatmap  

### 3. Enhanced Learning Experience
- 📚 Comprehensive learning hub with clear explanations  
- 🧮 Mathematical formulas for centrality measures  
- 💻 Downloadable code snippets using NetworkX  
- 🎯 Interactive quiz with feedback and scoring  
- 📊 Visual correlation analysis between centralities  

### 4. Improved User Interface
- 🎨 Custom CSS styling with themes and colors  
- 📱 Fully responsive design for all screen sizes  
- 📊 Real-time sidebar statistics  
- ✅ Input validation with error messages  
- 🗑️ Individual user removal and clear-all functionality  

### 5. Educational Components
- 🎓 Step-by-step tutorials in flashcards  
- 🧠 Knowledge quiz with instant feedback  
- 💡 Practical examples  
- 📥 Downloadable Python code  
- 🔬 Explanations of advanced concepts  

### 6. Enhanced Data Management
- 🧾 Form-based input with robust validation  
- 🏷️ Node highlighting for deeper insights  
- 🛣️ Shortest path finder between nodes  
- 📈 Sortable centrality tables  
- 🏘️ Community detection with size visualization

## 🛠️ Installation Instructions

1. **Create a project directory**:

    ```bash
    mkdir social-network-analyzer
    cd social-network-analyzer
    ```

2. **Save the app code as `app.py`** in this directory.

3. **Create and activate a virtual environment**:

    ```bash
    python -m venv venv
    # On Windows
    venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```

4. **Install the dependencies**:

    ```bash
    pip install -r requirements.txt
    ```

5. **Run the application**:

    ```bash
    streamlit run app.py
    ```
